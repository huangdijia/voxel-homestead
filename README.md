# 我的世界 · 方块纪行

一个可在电脑浏览器里游玩的第一人称体素沙盒游戏。当前交付阶段为 **M1：铁器生存闭环 + 创造模式**，使用原创像素贴图、独立世界种子和本地存档。

功能参照 Minecraft Java 1.21.1，目标分阶段对齐玩法与内容。当前不是原版全功能实现，也不兼容原版存档、模组或服务器协议。后续内容见 [功能覆盖表](docs/FEATURES.md)。

## 本地运行

需要 Node.js 22.12+（本机验证 Node 24）和 pnpm 9+。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。点击 **创建新世界**，选择生存或创造模式，准备完成后点击 **进入世界**。第一人称鼠标控制需要浏览器授予 Pointer Lock；建议在独立 Chrome 中游玩。部分嵌入式浏览器会拒绝鼠标锁定，可点击「使用拖动视角模式」：按住右键环顾，轻点右键使用，左键挖掘。

```sh
pnpm test             # 规则、世界、物理、存档及模拟回归
pnpm build            # TypeScript 检查 + 生产构建
pnpm preview          # 本地检查生产构建
pnpm test:benchmark   # CPU 地形/网格基准，不等同于实际浏览器帧率
```

## 首期包含

- 生存和创造模式，世界列表、创建、继续、导出、导入和删除。
- 平原、森林、丘陵、洞穴、煤铁矿、静态水体、昼夜、洞内遮光、火把照明。
- 9 格快捷栏、27 格储物格、4 个装备槽，2×2/3×3 手动合成与配方手册。
- 木、石、铁工具，铁甲；工作台、箱子、熔炉、玻璃、门、梯子、台阶、白床。
- 工具耐久和掉落规则、木炭、冶炼、肉类烹饪、生命/饥饿/氧气、跌落和溺水。
- 猪、白羊、僵尸、爬行者；近战、护甲减伤、爆炸、睡眠、死亡掉落和安全重生。
- 创造物品搜索、无限建造、自由飞行；中文设置与操作指南。

| 疾跑 / 潜行                  | Ctrl / Shift |

| 背包与合成 / 返回            | E            |
| 丢一个手持物品               | Q            |

| 创造模式切换飞行             | 双击空格或 F |

背包左键拿起/放下，右键拆分/放一个，Shift + 点击快速移动。点击可用配方可直接消耗材料制作；也可以把材料摆进合成格，点击输出格取走成品。创造物品放入**当前选中的快捷栏格**。打开背包或熔炉时世界继续运行，Esc 暂停菜单和切出窗口会暂停。

## 生存第一天

1. 砍树收集原木，用配方手册做木板、木棍和工作台。把工作台放在地上，右键打开。
2. 制作木镐，采集圆石升级石镐；石镐可以采铁矿，空手不能拿到矿物。
3. 用 8 块圆石制作熔炉。上格放原料、下格放燃料，每件熔炼需要 10 秒。原木也可烧成木炭，因此不采煤也能制作火把。
4. 烧粗铁得到铁锭，制作铁工具与铁甲。猎取猪羊后烹饪肉类，饥饿不足时右键持续进食；饱食后生命逐渐恢复。
5. 建一个有门、有照明的庇护所。3 块白羊毛与 3 块木板可以制作床；床占两格，夜晚附近没有怪物时可睡到天亮。
6. 白天使用床也会设置重生点。死亡会掉落物品和装备，及时回到原地可以拾回。

出生周边预留了基本资源，让不同种子的首日均可开始；更远处地形由种子决定。

## 存档

世界保存在当前浏览器、当前网站地址的 IndexedDB 中，运行时每 5 秒建立一次完整检查点。正常退出会等待保存完成。世界修改、背包、装备、箱子、熔炉进度、生物、地面掉落、时间和重生点一并保存。

按 **Esc → 导出当前进度**，可直接把内存中的最新世界快照下载为独立 JSON 文件，包含尚未落盘的进度；即使 IndexedDB 保存失败或正在等待写入，仍可用此入口备份。导出不会把失败的自动保存状态标成成功，请在浏览器下载列表确认文件。世界列表中的“导出”则读取最近一次成功保存的数据。本轮已验证独立 Chrome 导出文件真实落盘，并可在另一浏览器导入；内嵌浏览器的下载尚未确认成功，备份优先使用独立 Chrome。

导入会校验内容并创建新世界，不覆盖已有世界。不同浏览器或不同端口的本地存档互不共享，可通过导出／导入迁移。浏览器拒绝写入或存储空间不足时会显示失败状态；保留下载的 JSON 备份后再处理浏览器存储问题。

## 当前验证

- 最终规则测试 **134 项通过、1 项可选 CPU 基准跳过**；TypeScript 与生产构建通过。
- Chrome 在本机 M1／16GB、1440×900、视距 6 的 **900 秒实际渲染测试约 60 FPS，帧时间 p95 18.2 ms**。使用自动飞行测试路线，资源每 15 秒采样，不代表所有场景的绝对峰值。
- Chrome 和 Safari 已验证部分真实操作；生产版还完成 Chrome 实时导出→IAB 实际文件导入、铁器存档恢复，以及内嵌浏览器锁定失败后的拖动视角操作。Edge 尚未实测；IAB 下载、Chrome UI 文件导入及完整手动生存旅程仍有未验范围。具体证据与限制见 [验证记录](docs/VALIDATION.md)。

## 实现结构

- `src/engine`：确定性生成器、16³ 区块、Worker、暴露面网格、碰撞和射线选择。
- `src/game`：纯 TypeScript 模拟、命令、物品/配方注册表、库存、存档、渲染与声音。
- `src/ui`：中文菜单、HUD、背包、合成、容器和像素图标。
- `public/assets`：两张原创生成的生产用材质图集。
- `tests`：规则、持久化、物理、完整成长链及区块调度测试。

当前世界高度为 -16 至 95，视距 2–6 区块。光照采用垂直天空遮光与最多 8 个近处火把光源；动态流体、全方位光传播、繁殖、红石、更多维度及联机属于后续阶段。

可导入 [铁器工坊验收存档](docs/examples/iron-workshop.voxel.json) 查看设备和建筑；此示例含开发测试平台，正常新世界仍从空背包开始。
