# 我的世界 · 方块纪行

一个可在电脑浏览器里游玩的第一人称体素沙盒游戏。已实现 **M1：铁器生存闭环 + 创造模式**，本轮继续加入 **M2 的农业与猪羊养殖**，使用原创像素贴图、独立世界种子和本地存档。农牧增量的真实浏览器验收正在进行，M2 完整主世界生存尚未完成。

功能参照 Minecraft Java 1.21.1，目标分阶段对齐玩法与内容。当前不是原版全功能实现，也不兼容原版存档、模组或服务器协议。后续内容见 [功能覆盖表](docs/FEATURES.md)。

[打开在线站点](https://voxel-homestead.huangdijia.chatgpt.site)

## 本地运行

需要 Node.js 22.12+（本机验证 Node 24）和 pnpm 9+。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。点击 **创建新世界**，选择生存或创造模式，准备完成后点击 **进入世界**。第一人称鼠标控制需要浏览器授予 Pointer Lock；建议在独立 Chrome 中游玩。部分嵌入式浏览器会拒绝鼠标锁定，可点击「使用拖动视角模式」：按住右键环顾，轻点右键使用，左键挖掘。

```sh
pnpm test             # 规则、世界、物理、存档及模拟回归
pnpm build            # TypeScript 检查 + 生产构建
pnpm preview          # 本地检查生产构建
pnpm test:benchmark   # CPU 地形/网格基准，不等同于实际浏览器帧率
```

## 生存第一天

1. 砍树收集原木，用配方手册做木板、木棍和工作台。把工作台放在地上，右键打开。
2. 制作木镐，采集圆石升级石镐；石镐可以采铁矿，空手不能拿到矿物。
3. 用 8 块圆石制作熔炉。上格放原料、下格放燃料，每件熔炼需要 10 秒。原木也可烧成木炭，因此不采煤也能制作火把。
4. 烧粗铁得到铁锭，制作铁工具与铁甲。猎取猪羊后烹饪肉类，饥饿不足时右键持续进食；饱食后生命逐渐恢复。
5. 建一个有门、有照明的庇护所。3 块白羊毛与 3 块木板可以制作床；床占两格，夜晚附近没有怪物时可睡到天亮。
6. 白天使用床也会设置重生点。死亡会掉落物品和装备，及时回到原地可以拾回。

出生周边预留了基本资源，让不同种子的首日均可开始；更远处地形由种子决定。

## 开始种植与养殖

1. 在工作台制作锄头，对上方留空的草方块或泥土右键翻耕，再拿种子对耕地顶面右键播种。用 3 个铁锭制作铁桶，对水源右键装水，再对方块表面右键倒水；耕地周围横向 4 格范围、同层或高一层有水即可保持湿润。**水目前仍是静态方块，不会流动或自动形成无限水源。**
2. 保持光照，等待作物逐阶段长大；骨粉右键可加速，成熟作物不再消耗骨粉。左键收获成熟作物；干燥会减慢生长，空置耕地持续缺水后会恢复为泥土。小麦、胡萝卜和马铃薯各有 8 个阶段，甜菜有 4 个阶段。
3. 新世界自然生成草丛，徒手破坏有机会获得小麦种子。用 7 个木台阶合成堆肥桶，放入树叶、种子或作物，装满并熟成后右键取出骨粉；骨粉对草方块使用可长出草丛，旧世界也能通过这条路线获取种子。胡萝卜和马铃薯目前可由僵尸少量掉落取得。**甜菜种子目前仅能从创造物品栏取得，尚未打通自然生存来源。**
4. 3 个小麦可在工作台制作面包；马铃薯可入炉烤熟；6 个甜菜根加 1 个碗可制作甜菜汤，食用后归还碗。毒马铃薯有独立掉落机会，食用可能造成简化的中毒伤害，尚未实现完整持续药效系统。
5. 手持小麦吸引和喂食成年羊；胡萝卜、马铃薯或甜菜可吸引和喂食成年猪。喂两只同类成年动物，它们靠近并停留约 3 秒后产下一只幼崽；父母进入 5 分钟冷却，幼崽约 20 分钟长大，继续喂食可加速成长。这些时间只在世界模拟运行时推进。
6. 用 2 个铁锭制作剪刀，对成年白羊右键剪毛；刚剪过毛的羊和幼羊不能再次剪毛。剪毛后的羊站在草方块上累计吃草约 30 秒会重新长毛。当前没有驯养、坐骑、染色羊或其他可繁殖生物。

作物与养殖采用本项目的简化规则；雨水灌溉、踩踏耕地、完整生态、村民交易、经验、附魔、酿造、钓鱼及更多群系结构仍在后续范围内。各项实现和验收边界见 [M2 功能表](docs/FEATURES.md#m2完整主世界生存)。

## 存档

世界保存在当前浏览器、当前网站地址的 IndexedDB 中，运行时每 5 秒建立一次完整检查点。正常退出会等待保存完成。世界修改、背包、装备、箱子、熔炉进度、生物、地面掉落、时间和重生点一并保存；本轮新增耕地水分、生长进度、堆肥熟成、幼体年龄、繁殖冷却及剪毛状态。

新检查点使用存档版本 2。旧版世界保留生成器版本 1 的原地形，首次保存为新版时，在同一事务中保留升级前检查点，可从世界列表的“升级前备份”导出；新建世界使用会生成草丛的生成器版本 2。农业状态的保存、迁移及异常回滚已有自动化用例，真实浏览器农牧往返仍待本轮验收结果。

按 **Esc → 导出当前进度**，可直接把内存中的最新世界快照下载为独立 JSON 文件，包含尚未落盘的进度；即使 IndexedDB 保存失败或正在等待写入，仍可用此入口备份。导出不会把失败的自动保存状态标成成功，请在浏览器下载列表确认文件。世界列表中的“导出”则读取最近一次成功保存的数据。M1 生产版已验证独立 Chrome 导出文件真实落盘，并可在另一浏览器导入；内嵌浏览器的下载尚未确认成功，备份优先使用独立 Chrome。

导入会校验内容并创建新世界，不覆盖已有世界。不同浏览器或不同端口的本地存档互不共享，可通过导出／导入迁移。浏览器拒绝写入或存储空间不足时会显示失败状态；保留下载的 JSON 备份后再处理浏览器存储问题。

## 当前验证

- M1 基线规则测试 **134 项通过、1 项可选 CPU 基准跳过**，当时的 TypeScript 与生产构建通过。M2 已新增农业规则、交互、视觉、存档及独立审查用例；本轮最终统计与浏览器结果待主控汇总。
- M1 的 Chrome 本机 M1／16GB、1440×900、视距 6 **900 秒实际渲染测试约 60 FPS，帧时间 p95 18.2 ms**。使用自动飞行路线，资源每 15 秒采样，不代表所有场景的绝对峰值；该结果不能替代新增农田和养殖场景的性能验收。
- Chrome 和 Safari 已验证部分 M1 真实操作；M1 生产版还完成 Chrome 实时导出→IAB 实际文件导入、铁器存档恢复，以及内嵌浏览器锁定失败后的拖动视角操作。Edge 尚未实测；IAB 下载、Chrome UI 文件导入及完整手动生存旅程仍有未验范围。M2 浏览器农业脚本明确区分业务验证和展示夹具，当前尚未在此文档标记通过。具体证据与限制见 [验证记录](docs/VALIDATION.md)。

## 实现结构

- `src/engine`：确定性生成器、16³ 区块、Worker、暴露面网格、碰撞和射线选择。
- `src/game`：纯 TypeScript 模拟、命令、物品/配方注册表、库存、存档、渲染与声音。
- `src/ui`：中文菜单、HUD、背包、合成、容器和像素图标。
- `public/assets`：两张原创生成的生产用材质图集。
- `tests`：规则、持久化、物理、完整成长链及区块调度测试。

当前世界高度为 -16 至 95，视距 2–6 区块。光照采用垂直天空遮光与最多 8 个近处火把光源；动态流体、全方位光传播、更多生态系统、红石、其他维度及联机属于后续阶段。

可导入 [铁器工坊验收存档](docs/examples/iron-workshop.voxel.json) 查看设备和建筑；此示例含开发测试平台，正常新世界仍从空背包开始。
