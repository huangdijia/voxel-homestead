# 我的世界 · 方块纪行

一个可在电脑浏览器里游玩的第一人称体素沙盒游戏。已实现 **M1：铁器生存闭环 + 创造模式**，并加入 **M2 的农牧、自然更新、矿物装备、完整世界高度、经验附魔与铁砧／砂轮子集**，使用原创像素贴图、独立世界种子和本地存档。各项扩展有独立验证记录，M2 完整主世界生存尚未完成。

功能参照 Minecraft Java 1.21.1，目标分阶段对齐玩法与内容。当前不是原版全功能实现，也不兼容原版存档、模组或服务器协议。后续内容见 [功能覆盖表](docs/FEATURES.md)。

## 在线体验

[打开在线站点](https://voxel-homestead.huangdijia.chatgpt.site)

点击“进入世界”会请求全屏；**Esc 暂停并退出全屏**，E 开关背包。浏览器拒绝全屏时仍可窗口游玩。

## 本地运行

需要 Node.js 22.12+（本机验证 Node 24）和 pnpm 9+。

```sh
pnpm install
pnpm dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。点击 **创建新世界**，选择生存或创造模式，准备完成后点击 **进入世界**。第一人称鼠标控制需要浏览器授予 Pointer Lock；建议在独立 Chrome 中游玩。部分嵌入式浏览器会拒绝鼠标锁定，可点击「使用拖动视角模式」：按住右键环顾，轻点右键使用，左键挖掘。

```sh
pnpm test             # 规则、世界、物理、存档及模拟回归
pnpm build            # TypeScript 检查 + 生产构建
pnpm preview          # 本地检查生产构建
pnpm test:benchmark   # CPU 地形/网格基准，不等同于实际浏览器帧率
```

## 生存第一天

1. 砍树收集原木，用配方手册做木板、木棍和工作台。把工作台放在地上，右键打开。
2. 制作木镐，采集圆石升级石镐；石镐可以采铁矿，空手不能拿到矿物。
3. 用 8 块圆石制作熔炉。上格放原料、下格放燃料，每件熔炼需要 10 秒。原木也可烧成木炭，因此不采煤也能制作火把。
4. 烧粗铁得到铁锭，制作铁工具与铁甲。猎取猪羊后烹饪肉类，饥饿不足时右键持续进食；饱食后生命逐渐恢复。
5. 建一个有门、有照明的庇护所。3 块白羊毛与 3 块木板可以制作床；床占两格，夜晚附近没有怪物时可睡到天亮。
6. 白天使用床也会设置重生点。死亡会掉落物品和装备，及时回到原地可以拾回。

出生周边预留了基本资源，让不同种子的首日均可开始；更远处地形由种子决定。

## 开始种植与养殖

1. 在工作台制作锄头，对上方留空的草方块或泥土右键翻耕，再拿种子对耕地顶面右键播种。用 3 个铁锭制作铁桶，对水源右键装水，再对方块表面右键倒水；耕地周围横向 4 格范围、同层或高一层有水即可保持湿润。水会流动，桶只能回收源方块；双水源再生与撤源规则见下节。
2. 保持光照，等待作物逐阶段长大；骨粉右键可加速，成熟作物不再消耗骨粉。左键收获成熟作物；干燥会减慢生长，空置耕地持续缺水后会恢复为泥土。小麦、胡萝卜和马铃薯各有 8 个阶段，甜菜有 4 个阶段。
3. 新世界自然生成草丛，徒手破坏有机会获得小麦种子。用 7 个木台阶合成堆肥桶，放入树叶、种子或作物，装满并熟成后右键取出骨粉；骨粉对草方块使用可长出草丛，旧世界也能通过这条路线获取种子。胡萝卜和马铃薯目前可由僵尸少量掉落取得。**甜菜种子目前仅能从创造物品栏取得，尚未打通自然生存来源。**
4. 3 个小麦可在工作台制作面包；马铃薯可入炉烤熟；6 个甜菜根加 1 个碗可制作甜菜汤，食用后归还碗。毒马铃薯有独立掉落机会，食用可能造成简化的中毒伤害，尚未实现完整持续药效系统。
5. 手持小麦吸引和喂食成年羊或牛；胡萝卜、马铃薯或甜菜可吸引和喂食成年猪。喂两只同类成年动物，它们靠近并停留约 3 秒后产下一只幼崽；父母进入 5 分钟冷却，幼崽约 20 分钟长大，继续喂食可加速成长。这些时间只在世界模拟运行时推进。
6. 用 2 个铁锭制作剪刀，对成年白羊右键剪毛；刚剪过毛的羊和幼羊不能再次剪毛。剪毛后的羊站在草方块上累计吃草约 30 秒会重新长毛。当前没有驯养、坐骑或染色羊。

作物与养殖采用本项目的简化规则；雨水灌溉、踩踏耕地、完整生态、村民交易、其余附魔、酿造、钓鱼及更多群系结构仍在后续范围内。各项实现和验收边界见 [M2 功能表](docs/FEATURES.md#m2完整主世界生存)。

## 水流、熔岩与树木更新

- 放出的水与熔岩优先向下流动，有支撑后向水平方向扩散；水最远 7 格，熔岩最远 3 格。撤去唯一来源后，无其他供给的流动部分逐步退去。两个相邻水源可在有支撑的中间格再生水源，新源随后独立存在；熔岩不会这样再生。
- 水接触熔岩源可生成黑曜石，接触流动熔岩可生成圆石；熔岩从上方遇水可生成石头。铁桶只收取源方块。熔岩桶可作熔炉燃料，点燃后留下空桶；熔岩会伤害玩家和生物、烧毁掉落物。钻石镐可采集黑曜石；传送门成长链仍未实现。
- 沙子和沙砾失去支撑后逐格下落；遇到台阶、床、耕地或植物等不适合完整方块落位的支撑时，保留支撑物并掉成物品。当前没有平滑下落实体动画或砸伤效果。
- 砍掉原木后，无法通过连续树叶在 6 步内连接原木的原生叶会随机衰减，可能掉落橡树苗、木棍或苹果。玩家放置的叶子不会自然衰减。把树苗种在草方块或泥土上，留足树冠空间并保持光照，可等待生长或右键使用骨粉；空间、光照或加载范围不足时不扣骨粉。

更新只在世界模拟运行、相应区域已加载且靠近玩家时推进。天气、完整方块光传播、水浸方块、流体推力、熔岩引燃周围方块及离开熔岩后的持续燃烧仍未实现。具体规则、兼容方式和验收边界见 [自然更新说明](docs/NATURAL-UPDATES.md)。

## 继续采矿与制作装备

新建世界可找到铜、金、红石、青金石、钻石和绿宝石，以及深层矿石和深板岩。铁镐能采集钻石；在工作台用 3 个钻石和 2 根木棍制作钻石镐，再采集由水与熔岩源生成的黑曜石。金工具速度快但采集等级低、耐久少，不能代替铁镐采钻石。

新增金／钻石各五种工具和四件护甲，钻石甲带韧性。矿物材料可以压块存放并拆回，粗铜和粗金可熔炼。新世界高度为 **y = −64…319**，包含深层洞穴、矿物高度偏好和高山，区块随玩家上下移动加载。矿物规则见 [矿物与装备说明](docs/MINERALS.md)，新高度、生成器及验收边界见 [世界高度说明](docs/WORLD-HEIGHT.md)。红石电路、铜氧化、完整附魔、交易、传送门及完整主世界范围尚未完成。

## 制作附魔装备

在新世界水岸采集甘蔗，种在水边等待生长；成年牛可猎取皮革。用甘蔗造纸，纸加皮革制书，再用书、钻石和黑曜石制作附魔台。右键台面，放入未附魔装备和青金石；三档先要求达到显示等级，实际仅扣 1／2／3 级和对应数量的青金石。创造模式无需也不扣这两种资源。

有效书架最多 15 个，与附魔台隔一格，放在同层或高一层。经验来自合格采矿、击杀、繁殖和领取熔炉产物。首批八种为效率、耐久、时运、精准采集、锋利、保护、摔落缓冲和水下呼吸；附魔书、铁砧、砂轮和其余附魔尚未完成。材料、规则、存档与真实验收范围见 [经验与附魔说明](docs/ENCHANTING.md)。

## 存档

世界保存在当前浏览器、当前网站地址的 IndexedDB 中，运行时每 5 秒建立一次完整检查点。正常退出会等待保存完成。世界修改、背包、装备、箱子、熔炉进度、生物、地面掉落、时间和重生点一并保存；还包含耕地水分、生长进度、堆肥熟成、幼体年龄、繁殖冷却、剪毛状态，以及流体任务和自然更新的随机状态、队列与暂存下落方块；新增经验、附魔种子与装备效果、熔炉经验、甘蔗生长状态。

新检查点使用**存档版本 7**，读取兼容版本 1–7。旧世界保留各自生成器 1–6，首次保存为新版时，在同一事务中保留对应版本的升级前检查点，可从世界列表的“升级前备份”导出。新建世界使用生成器 7，在出生点附近生成海湾与别墅；区域以外沿用生成器 6 的地形，地下 Y < 48 保持原有矿物与洞穴。格式升级不会重写旧世界地形；海边别墅需要新建世界体验。步枪会随背包正常保存，死亡后也可再次按 G 领取。

上一轮 Chrome 已验证 4 次农牧检查点回读一致，以及版本 1→2 升级、备份下载和独立恢复，详见 [M2 验证](docs/M2-VALIDATION.md)。此前自然更新脚本的 3 次版本 3 检查点比较一致；页面刷新后继续游戏，方块、流体／自然更新和背包已逐项一致，并保留真实截图，详见 [自然更新说明](docs/NATURAL-UPDATES.md)。

按 **Esc → 导出当前进度**，可直接把内存中的最新世界快照下载为独立 JSON 文件，包含尚未落盘的进度；即使 IndexedDB 保存失败或正在等待写入，仍可用此入口备份。导出不会把失败的自动保存状态标成成功，请在浏览器下载列表确认文件。世界列表中的“导出”则读取最近一次成功保存的数据。M1 生产版已验证独立 Chrome 导出文件真实落盘，并可在另一浏览器导入；内嵌浏览器的下载尚未确认成功，备份优先使用独立 Chrome。

导入会校验内容并创建新世界，不覆盖已有世界。不同浏览器或不同端口的本地存档互不共享，可通过导出／导入迁移。浏览器拒绝写入或存储空间不足时会显示失败状态；保留下载的 JSON 备份后再处理浏览器存储问题。

## 实现结构

- `src/engine`：确定性生成器、16³ 区块、Worker、暴露面网格、碰撞和射线选择。
- `src/game`：纯 TypeScript 模拟、命令、物品/配方注册表、库存、存档、渲染与声音。
- `src/ui`：中文菜单、HUD、背包、合成、容器和像素图标。
- `public/assets`：两张原创生成的生产用材质图集。
- `tests`：规则、持久化、物理、完整成长链及区块调度测试。

当前建造高度为 −64 至 319，视距 2–6 区块，采用有界的三维加载窗口。光照采用整列天空遮光与最多 8 个近处火把光源；完整光传播、天气、剩余流体交互、更多生态系统、红石、其他维度及联机属于后续阶段。

可导入 [铁器工坊验收存档](docs/examples/iron-workshop.voxel.json) 查看设备和建筑；此示例含开发测试平台，正常新世界仍从空背包开始。
