## 真实游戏的铁器链集成

[铁器链原始 JSON](browser-acceptance.json) 记录 `scripts/browser-acceptance.mjs` 对真实 Game、VoxelWorld、Worker 和 IndexedDB 的运行结果：**6 个阶段通过**，推进模拟 539.5 秒、墙钟 6.442 秒，错误列表为空。

该测试从空背包生存世界开始，但明确摆放了近处测试资源、平台、小屋外壳并设置玩家位置：20 原木、11 圆石、33 粗铁、3 羊毛来自测试资源方块；直接库存赠送为 0。采集、合成、熔炼和可交互设备放置走实际规则，最终得到 4 种铁工具和全套铁甲，完成床、门、箱子及木炭火把。木炭熔炼中、铁熔炼中、最终状态的三份 IndexedDB 检查点均一致。

这证明实际游戏系统的铁器规则链与存档整合，不等于手动自然生存通关；小屋外壳也不计作手工建屋。可导入 [铁器工坊验收存档](examples/iron-workshop.voxel.json) 检查成果，该示例含测试平台，不是自然生存存档或默认赠送物品。

## 900 秒真实渲染性能

[原始性能 JSON](browser-performance.json) 状态为 `complete`。在 Chrome 152.0.7977.82、本机 M1／16GB，以 **1440×900、DPR 1、中等画质、视距 6、FOV 75** 连续运行 900.0003 秒；共采集 53,999 个帧间隔，隐藏帧和暂停帧计数均为 0。

| 指标 | 本轮结果 | 目标／解释 |
| --- | --- | --- |
| 平均帧率 | **59.99887 FPS** | ≥55 FPS，通过。 |
| 帧时间 p95 | **18.2 ms** | ≤33 ms，通过。 |
| 区块数量 | 676–845 | 下述 61 个资源样本的观测范围。 |
| 几何体／贴图 | 350–728／3–5 | 样本观测范围；包含生物与手持资源。 |
| 待处理区块任务／保存队列 | 0–2／0–1 | 样本观测范围，不代表采样间绝对峰值。 |
| Draw calls | 215–348 | 样本观测范围，视野变化会改变绘制数量。 |
| JavaScript 堆 | 103.32–138.09 MB | 样本观测范围，MB 按 1,000,000 字节换算。 |
| 返回原区域 | 676 区块、663 几何体、5 贴图；两类队列均为 0 | 结束后再观察 61.373 秒，上述资源数量保持一致；堆由结束时 116.94 MB 变为 127.49 MB，仍在本轮样本范围内。 |

`scripts/browser-performance.mjs` 用真实墙钟驱动独立创造世界以约 4 格／秒沿方形路线飞行，同时运行渲染器、Worker 流式加载、模拟、生物与自动保存，最后回到起点。**资源状态约每 15 秒采样，共 61 份；表中范围是离散样本的最小／最大值，不是连续监测得到的绝对峰值。** 平均 FPS 与 p95 则由游戏采集的帧间隔计算。

本轮达到约定帧率目标，并观察到返回区域后的资源数量稳定；不能据此证明所有场景无内存泄漏或其他浏览器达到相同结果。轨迹由开发夹具设定，不代替键鼠可用性验证。基准完成后仅补充世界边界守卫和暂停菜单的实时备份导出，未改渲染逻辑；这些改动已纳入最终规则测试与生产构建，未再次运行完整 900 秒基准。
