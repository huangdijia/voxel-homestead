# 数据目录之外的行为验收门槛

以下是明确待关闭的行为条目，不是另一份“功能已完成”总表。注册了 `redstone_wire` 不代表红石网络可用；存在 `pig` 不代表繁殖、幼体、驯养和骑乘完整；列出命令节点也不代表权限与执行语义正确。所有条目状态为 **待逐项核验**；表中的阶段是目标排期，已有局部实现需补足行为与浏览器证据后才能关闭。

范围固定 Java 1.21.1 的玩法和功能，独立存档，不要求原版服务器协议、模组/原版存档兼容或漏洞复现。涉及精确更新顺序的 Java 特有行为，必须把具体可观察结果写成用例；尚未验证的相似表现不可称为对齐。此表仍是首轮行为分解，需随数据缺域补齐，不能宣称已穷举一切隐含规则。
