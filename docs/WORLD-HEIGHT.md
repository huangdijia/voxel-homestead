# M2 世界高度与垂直探索

本轮把世界的可建造坐标扩展为 **y = −64…319**，新世界使用生成器 5，存档检查点使用版本 5。Minecraft 的这一主世界高度范围参照[官方洞穴与山崖说明](https://www.minecraft.net/article/caves---cliffs-part-ii-the-features)。本项目仍使用独立地形算法，不代表已经对齐原版的地貌、群系、结构和矿脉密度。

## 玩家可见变化

- 新世界的海面在 y = 63，最顶层水方块的坐标是 62；原点出生区有稳定陆地、附近橡树和地下资源。
- 深层延伸到 −64，底部有基岩，0 以下主要为深板岩；洞穴深入地底，低于 −54 的部分洞穴可生成熔岩。
- 煤、铁、铜、金、红石、青金石、钻石和绿宝石按高度偏好生成，浅层和深层也有沙砾矿团。钻石偏向深层，铁也可出现在高处山地，绿宝石偏向高地。分布是独立近似，不应直接套用原版产量经验。
- 可以在 319 层放置方块；320 层的放置会被拒绝且不消耗物品。双格门可放在 318／319 层，超过顶界的整扇门不会只放一半。
- 玩家在创造模式可以飞到建造范围之外。边界外为空气，正常移动不会越入尚未加载的区块；掉入世界底部以下 64 格的虚空后会触发死亡或创造模式回位。

高度常量见 [world-height.ts](../src/engine/world-height.ts)，版本化生成见 [generator.ts](../src/engine/generator.ts)。

## 垂直区块与规则

16³ 子区块随玩家的横向和纵向位置加载、卸载。视距 6 时，完整窗口上限为 **13³ = 2,197 个子区块**，接近世界边缘时裁剪；另可能有一个已过期但尚未返回的 Worker 任务。历史建筑修改独立保存，不会把远处高层区块永久钉在内存中。

碰撞、准星射线、流体、下落方块、作物、树苗、容器和生物均检查所在高度的加载状态。跨未加载层的处理会延后；双格门操作与掉落物移动也遵守这个规则。重生安全点根据种子和已保存的完整方块数据判断，随后等待目标区块加载，不会因为高处床暂未驻留而误判床失效。

天空遮挡按整列数据查询，包含未驻留的高层建筑和自然树木；拆掉屋顶会使缓存失效。主线程天空缓存最多 4,096 列，并在水平离开区域时清理；Worker 屋顶缓存最多 65,536 列，按世界、种子、生成器及列修改内容区分。这仍是垂直天空遮挡，不是完整的方块光传播。

## 旧世界与存档

读取兼容存档版本 1–5。旧版本仍按其原有高度范围校验，不能把高层修改伪装为旧存档。旧档第一次写成版本 5 时，同一 IndexedDB 事务会保留升级前的完整检查点；再次保存不会覆盖这份备份。

旧世界继续使用原生成器 1／2／3／4，包括尚未探索区域；新建世界才使用生成器 5。旧世界的已有地形不会拉伸或替换，升级格式后可以在原有地形上继续向高处建造。低于旧地底的旧版基岩语义也保持。版本 1–4 的固定方块采样与地表高度哈希全部保留回归。

旧矿物版的自然采矿、PWA 和迁移证据仍见 [MINERALS.md](MINERALS.md)；其中的生成器 4、−16…95 和旧测试数量属于历史版本记录。
