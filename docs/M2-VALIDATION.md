# M2 农牧增量验证

日期：2026-09-05。本次交付为 M2 的农业与猪羊繁殖子集，完整主世界、其他维度和多人仍在后续覆盖表中；不表示 Minecraft Java 1.21.1 全功能对齐。

## 已实现规则

四类分阶段作物（小麦、胡萝卜、马铃薯、甜菜）、干湿耕地、附近静态水源灌溉、光照与生长、骨粉、收获、面包／烤马铃薯／甜菜汤、堆肥、铁桶移水、三种锄、剪刀、猪羊食物吸引／喂养／繁殖／幼体成长和羊毛再生。新世界使用生成器 2，生成自然草丛；旧世界保留生成器 1，仍可通过树叶堆肥、骨粉长草取得小麦种子。胡萝卜和马铃薯有僵尸稀有掉落来源，甜菜种子目前仅创造模式可取得。

光照、生长时序、动物寻路及有毒马铃薯效果采用本项目近似规则；水仍为静态水源。大规模牧场、跨浏览器自然游玩全过程和新生成器的 900 秒性能回归没有在本记录中宣称通过。

## 真实浏览器农牧流程

[原始记录](browser-agriculture.json)于北京时间 2026-09-05 09:01:46 开始，在 Chrome 的 Vite 开发版世界“麦风农场 · 完整回归”（种子 `M2-farming-20260905`）运行。真实 `Game`、`Simulation`、`VoxelWorld`、Worker 网格和 IndexedDB 接通；**9 个阶段全部通过，其中 8 个为业务检查（含空世界前置检查），1 个为展示夹具**，记录无错误。

| 阶段 | 本次实际结果 |
| --- | --- |
| 空世界前置检查 | 初始库存、修改方块、掉落与生物均为空。 |
| 开垦与播种 | 5 格干耕地，消耗 5 粒小麦种子与 5 点木锄耐久。 |
| 水桶灌溉 | 移走唯一水源并倒入灌溉孔，仍只有 1 个桶；5 格耕地全部湿润。倒水射线实际命中 `(0,31,-6)` 孔底石块的上表面。 |
| 生长与骨粉 | 推进 61 个模拟秒后，5 株小麦从阶段 0 长到阶段 1／2；再消耗 10 份骨粉全部催熟，成熟后再次使用不扣骨粉。 |
| 收获、面包与进食 | 拾取 5 份小麦及 9 粒种子；3 份小麦制成并吃掉 1 个面包，饥饿值从显式设置的 10 回到 15；余下 2 份小麦用于喂羊。 |
| 堆肥与中途保存 | 消耗 16 片树叶装满堆肥桶，在剩余约 0.5 秒时保存回读；熟成后取得并拾取 1 份骨粉。 |
| 猪羊繁殖 | 2 份小麦与 2 根胡萝卜喂养 4 个成年夹具生物，推进 3.25 个模拟秒后各得到 1 只幼羊、幼猪，4 个亲本进入约 300 秒冷却。 |
| 剪毛 | 成羊掉落并拾取 1 份羊毛，剪刀耐久 238 → 237；重复剪毛不重复掉落、不扣耐久。 |
| 展示夹具 | 业务完成后直接摆放四类作物共 28 个生长阶段方块，并追加展示用物品；保留真实繁殖的两只幼崽和刚剪毛的成羊。 |

模拟采用固定 `0.05` 秒步长，累计加速推进 **73.6 个模拟秒**；整次脚本真实墙钟耗时 **4,089 毫秒**。这些时间用于说明加速验收方式，不是自然游玩耗时或渲染性能基准。结束时 Worker 待处理任务为 0，记录到 125 个区块、134 次绘制调用和 48 个几何资源；该单次快照不证明长期资源稳定性。

业务输入均有显式记录：木锄、铁桶、剪刀、工作台、堆肥桶各 1 个，5 粒小麦种子、24 份骨粉、64 片树叶、2 根胡萝卜，以及 2 只成年羊和 2 只成年猪。脚本另建造地面高度 32 的 702 格草地平台、一个水源及两个畜栏，直接设置各次玩家站位，把后来自然生成的 6 只动物移出喂养射线，并在进食前把饥饿值设为 10。交互通过程序调用正式游戏命令，挖掘／时间推进直接调用模拟接口；本记录不把这些输入、站位或展示物品计为从零生存获取，也不宣称已经完成全程键鼠操作。

**4 次真实 IndexedDB 检查点全部逐项一致**：堆肥熟成中途、两只幼崽与亲本冷却、剪毛后的业务终点、最终展示夹具。比较玩家、修改方块、容器、生物、掉落、农业随机状态与计时、堆肥计时、世界时间及累计游玩时间。前三次各有 5 条耕地记录，展示阶段增至 33 条；脚本完成保存回读，但没有重新加载浏览器页面。旧存档升级与备份下载的独立浏览器证据见下一节。
