# 素材说明与检查记录

本项目 M1 使用两张原创生成的 PNG 图集。生成来源为本次开发过程中使用的内置 `image_gen` 工具，采用经典方块像素风；它们不是从 Minecraft 游戏文件或官方资源包中提取的素材。图集用于独立游戏的视觉表现，不提供 Minecraft 原版资源包兼容性。

本说明依据仓库中的实际文件、当前采样代码，以及 2026-09-05 对两张 PNG 的逐张视觉检查编写。生成目标为原创、正交平铺、无文字的经典方块像素图集；实际输出以本页尺寸及视觉限制为准。

生成工具输出记录：地形 `exec-99787677-4778-4706-a47c-ac9a8c2f0610.png`，生物 `exec-527f6c67-6a36-4562-a1a4-dbb28a448b9a.png`。两张原始工具输出与仓库生产文件的 SHA-256 已逐一核对相同，未二次裁切或重绘。

当前 [网格构建器](../src/engine/mesher.ts) 按方块面选择纹理：草地顶面、侧面和底面分别采样；原木端面与树皮分开；工作台和熔炉使用各自的特征面。门、梯子、台阶、床等由几何形状配合既有图格组成，没有独立完整纹理组。水、玻璃、床垫、枕头及火把亮部会复用白羊毛等图格，并叠加颜色、透明度或发光材质。

视觉检查确认 16 个位置均有可辨识的对应内容；未发现可见文字标签、水印或空白图格。草顶含少量白色花点；工作台为木质网格图案；熔炉正面本身绘有橙色火焰。这些细节属于图像内容：例如花点不是独立植物实体，熔炉也没有配套的熄火图格或动画帧。

当前 [生物渲染器](../src/game/EntityRenderer.ts) 将对应象限贴到头部正面平面；身体、四肢和头部其他面使用程序构建的方块模型与纯色材质。该文件是四张脸的图集，不是四套完整的角色皮肤 UV 展开图，也不包含动作序列。

逐张检查可辨识四类生物的脸部特征，未发现可见文字、水印或缺失象限。脸部图像使用较大的色块、局部明暗渐变和风格化五官；僵尸的左右眼呈现不对称形态。因此它们与地形图格具有相近的块状风格，但像素尺度和细节密度并不完全一致。

## 当前采样与像素限制

- 两张源图都是 1254 × 1254，并非原生 16 × 16 或 32 × 32 像素的单块素材。可见“大像素”主要是生成图像中的块状笔触，局部包含渐变和柔化边缘；最近邻采样不会把源图自动变为严格的低分辨率像素网格。
- 地形宽高不能被 4 整除，均分后的图格宽高为 **313.5 像素**。当前使用归一化 UV 四等分，格边界存在半像素位置；没有逐格裁切或补齐为整数尺寸。近看边缘、远距离缩小或不同屏幕缩放下，仍可能出现邻格取样、细线或闪烁，需要以实际运行画面判断。
- 地形纹理使用 sRGB、最近邻放大/缩小，并关闭 mipmap；UV 在每个图格内缩 `0.001`，相当于源图约 0.3135 像素的内缩，并非完整的一像素保护边。源图没有专门的图格外扩留白。该设置保持块状观感，但不保证任意距离的抗闪烁或无接缝。
- 生物纹理使用 sRGB 和最近邻采样，以 `repeat = 0.5`、象限偏移取图；当前没有额外的象限内缩边。2 × 2 边界可以整数分割，但人物脸部放大后的清晰度仍受源图笔触和屏幕采样影响。
- 这些图格尚未经过逐边平铺一致性验证；视觉可辨识不等于所有边缘均可无缝重复。水/玻璃复用纹理、有限火把点光、固定朝向特殊方块等表现边界另见 [功能覆盖表](FEATURES.md)。
- 本次完成的是文件完整性、布局与可见内容检查，不代表原版美术一致性验收、用户最终视觉认可，或所有浏览器与距离档位的画面验收。运行证据应与 [验证记录](VALIDATION.md) 一并查看。

后续如替换任一图集，应同步更新尺寸、SHA-256、格子布局及对应采样代码，并重新检查实际游戏中的方块边缘、透明材质和生物正面。

## 铁与旧书增量
