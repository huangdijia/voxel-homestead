日期：2026-09-05。本轮在 Chrome 152.0.7977.82 验证本地生产预览 `http://127.0.0.1:4173/`；线上部署由独立发布任务处理，本文不把本地通过等同于线上已更新。

- `pnpm build`：TypeScript 与 Vite 生产构建通过。最终主文件 `index-CI9mWeuq.js`，874.26 KB／gzip 244.55 KB；主文件超过 500 KB 的体积提示仍存在。

## 全屏与 Esc

[原始状态记录](browser-fullscreen.json)。在生产版通过 Chrome 原生窗口点击“进入世界”，实际同时取得 Fullscreen 与 Pointer Lock：`fullscreenElement` 为 `app in-game`、鼠标已捕获。

实际按 E 打开背包，画面保持全屏并释放鼠标；随后按原生 Esc，全屏和鼠标捕获都退出，页面显示“游戏已暂停”。开发版另外验证了备用拖动视角：进入全屏后按 Esc，模拟的 `paused` 变为 `true`、`overlay` 为 `pause`。全屏拒绝会提示并允许窗口游玩；异步请求取消、销毁和 Safari 事件式锁鼠标路径有事件测试覆盖。全屏测试未直接触发 `blur` 或 `visibilitychange`，不将暂停方法测试算作失焦事件验收。

早期后台标签页中的自动点击被浏览器拒绝锁鼠标，不能据此判作全屏通过；激活原生 Chrome 窗口后的生产操作取得了上述成功结果。截图：[离线全屏世界](screenshots/pwa-offline-fullscreen.png)、[Esc 后的暂停](screenshots/pwa-escape-paused.png)，文件尺寸为 1384×844。

## 原生安装入口

Chrome 的 `Page.getAppManifest` 无解析错误，`Page.getInstallabilityErrors` 返回空数组。页面收到真实安装事件并显示“安装应用”；实际点击后出现 Chrome 的“安装应用”窗口，名称为“方块纪行 · 耕作与牧场”，来源为 `127.0.0.1:4173`。

验收选择了原生窗口的“取消”，页面正确显示“已取消安装，仍可在浏览器里继续玩”。**没有在此测试中完成桌面应用安装，也没有用模拟事件冒充安装成功**。生产功能在收到真实 `appinstalled` 后才显示完成；不支持页面内安装事件的浏览器显示安装说明。Chrome／Edge 和 Safari 的安装操作见 [PWA 说明](PWA.md)。

## 离线与存档

[完整原始记录](browser-pwa.json)。生产 Service Worker 激活并控制页面后，对验收标签页启用网络离线模拟、禁用普通 HTTP 缓存，并确认 `navigator.onLine=false`；一个未缓存的同源探测请求真实失败。随后仍能：

1. 刷新并显示完整首页及本机世界列表。
2. 打开已有世界，完成地形 Worker 加载，渲染贴图与生物。
3. 离线进入全屏、捕获鼠标，使用 E 背包与 Esc 暂停。
4. 保存返回并再次刷新，世界仍存在；真实 IndexedDB 读取确认时间为 1376、累计游玩约 18.8 秒，36 格空背包保持一致，旧存档升级为版本 2 且生成器保持 1，并出现升级前备份入口。

测试结束已恢复网络、普通缓存和窗口尺寸覆盖。应用资源缓存不读取、上传或清理存档数据库；新版不强制激活或自动刷新正在运行的游戏。浏览器离线测试后仅修改背包关闭按钮的一处提示，从“E / Esc”改为“E”，再通过上面的最终全量检查；未改变缓存和全屏逻辑。

## 尚未外推的范围

Edge、Safari 的实际 PWA 安装以及桌面应用独立窗口的完整游玩未实测；不继承 M1 的 Chrome／Safari 全部结论。新农牧版本没有重跑 900 秒性能测试。首次完整缓存前、浏览器清除网站数据后或限制本地存储时，不能保证离线启动；安装不代替存档导出备份。
